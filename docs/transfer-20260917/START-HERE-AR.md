# نسخة نقل AI-Engineer — r50 — 17 سبتمبر 2026

هذه حزمة **AI-Engineer داخل AutoCAD**، وليست RoadGuardian أو DriveCare.
الإصدار الأساسي ما زال 0.18.0؛ r50 اسم مرشح النقل وليس إعلان إصدار نهائي.

## ما بداخلها

- آخر الكود، إضافة AutoCAD المصدرية، وامتداد VS Code Operator 0.1.6.
- المحادثة العامة `Copilot` وواجهة تنفيذ أهداف المشروع `Project Agent`.
- زر التقاط المكونات ومعاينة نقل بلوكات موجودة بعد مراجعة البيانات والموافقات.
- جميع ملفات الاختبارات والوثائق وقائمة العمل الحالية.
- مشروع لوحة Hutchison Ports: R01/R02/R03 ومصادر المكونات الـ17، والـLISP
  وجداول البارت نامبر وبصمات المصادر وتقارير المراجعة.
- مثبّت نقل يتحقق من بصمات الملفات ويرفض الكتابة فوق مجلد قديم.

لا تشمل الحزمة مفاتيح Gemini أو رموز الخدمة أو المحادثات السابقة أو سجل تشغيل الجهاز
أو كامل workspace؛ تشمل فقط ملفات اللوحة المذكورة اللازمة للعمل الحالي.
لا تشمل تاريخ Git؛ مجلد العمل الأصلي ليس مستودع Git صالحًا حاليًا.

## التشغيل على الجهاز الآخر

1. انسخ ZIP الخارجي إلى الفلاشة، ثم فكّه على الجهاز الآخر.
2. يلزم Windows وPython 3.13 وVS Code وAutoCAD 2021 أو 2023.
   تراخيص البرامج ومفتاح Gemini يوفرها صاحب الجهاز؛ لا يحملها ZIP.
3. افتح PowerShell داخل المجلد الذي فككته، وثبّت في **مجلد جديد قصير المسار**:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\INSTALL-TRANSFER.ps1 -Destination C:\AI-Engineer-r50
Set-Location C:\AI-Engineer-r50
python -m pip install -r requirements.txt
python launcher.py check
```

4. على AutoCAD 2021:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\START-AI-ENGINEER-WITH-GEMINI.ps1 -AutoCADYear 2021 -DrawingPath .\workspace\review-drawings\HUTCHISON_PANEL_GA_PREVIEW_R03.dwg
```

على AutoCAD 2023 بدّل `2021` إلى `2023`. إذا اختلف مجلد تثبيت AutoCAD أضف
`-AutoCADRoot 'المسار الحقيقي لمجلد AutoCAD'`.

5. سيطلب المشغل `YES` ثم مفتاح Gemini بصورة مخفية. لا ترسله إلى الشات.
   تُبنى DLL من جديد على الجهاز الآخر مقابل مكتبات Autodesk الخاصة به.
6. ابدأ باختبار حالة الرسم للقراءة فقط؛ لا تعتبر فحص المتطلبات دليلاً على نجاح التشغيل
   الفعلي. الدعم الحي لـAutoCAD 2023 لم يُعتمد بعد على جهاز ثانٍ.

## الحالة الحقيقية وما يجب استكماله

نجح على الجهاز الأصلي تجميع AutoCAD 2021، وتجربة المحادثة العامة مع Gemini سابقًا.
آخر مجموعة اختبارات التطوير والنقل: **175 passed**، ومنها تثبيت نقل نظيف محليًا
ورفض مجلد موجود ورفض ملف تالف. ليست هذه نتيجة اختبار
شامل لكل المشاريع، ولا إثباتًا لنجاح التنفيذ الجديد داخل الرسم.

**تحريك البلوكات فعليًا غير مفعّل بعد**؛ الأداة الجديدة تنتج خطة معاينة فقط وتعيد
`execution_ready=false`. نسخة r49 التي شُغلت سابقًا أقدم من هذا الكود.

ترتيب الاستكمال:

1. التقاط حدود البلوكات الأصلية وفحص Xref والبلوكات الديناميكية والمجموعات.
2. مطابقة بصمة الرسم المحفوظ والـHandles والمواضع والدوران والمقياس مع السياق.
3. فحص التداخلات وحدود اللوحة ومناطق الفصل ومسافات المصنع المعتمدة.
4. ربط المعاينة بمسار Milestone 18 وموافقة محددة أحادية الاستخدام.
5. تنفيذ supported-API على Scratch مع استرجاع وفحص العناصر المنقولة وغير المنقولة.
6. تسليم ملف جديد بعد التحقق، ثم اختبار حي منفصل داخل AutoCAD.
7. استكمال التأكيدات الهندسية للوحة قبل أي ملف تصنيع. R03 ما زال مراجعة أولية.

حد المعاينة الحالي: 1..32 بلوكًا مسمى ظاهرًا داخل Model، وحدات mm، XY فقط، ملف DWG
حتى 2 MiB، والرسم بدون تعديلات جوهرية غير محفوظة. التسميات والخطوط المنفصلة لا تتحرك
تلقائيًا مع البلوك؛ يجب مراجعة ربطها.

## عوائق قد تظهر في الاختبارات الكاملة

قائمة العمل تسجل تجربة project_config يتيمة تستورد وحدة غير موجودة، واختبارًا لوثيقة
الأداء يتوقع عبارة قديمة. افحصهما ولا تمسح اختبارات المستخدم لتجميل النتائج.
ابدأ بالاختبارات المركزة، واستخدم مجلد temp قصيرًا على Windows.

```powershell
$env:PYTHONPATH=(Get-Location).Path
python -m pytest -q -p no:cacheprovider tests/test_autocad_component_moves.py tests/test_developer_agent.py tests/test_api.py tests/test_autocad_context.py tests/test_package_manager.py tests/test_operator_bridge.py tests/test_transfer_bundle.py
```
